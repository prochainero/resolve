設定

API 金鑰
到 Google AI Studio 的「Get API key」免費建立，貼在這裡。金鑰只存在這個瀏覽器。

模型
標示 Paid 的模型需要付費帳號。免費帳號請先試沒有 Paid 標示的；額度用完（429）時換一個。

思考程度
越高越準但越慢、越耗額度。結構式和反應機構建議用中或高。若模型不支援會顯示錯誤，改回「預設」即可。

圖片會送到 Google 處理；免費層的內容可能被用於改進產品，請不要上傳不想外流的資料。爭點資料只存在這台裝置的瀏覽器，清除瀏覽資料會消失，請定期匯出。
