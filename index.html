雲端同步（GitHub Gist）

用 prochainero 登入 GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token，只勾「gist」，並設定到期日。同步密碼自訂（建議 12 字以上），用來在瀏覽器內加密；筆記與 API 金鑰上傳前都會加密，GitHub 只看得到亂碼。忘記密碼就無法解開。每台裝置各輸入一次 token 和密碼即可。

會覆蓋資料前，系統會先請你另存備份檔。備份只含筆記文字、資料夾、API 設定與縮圖，通常不到幾 MB。

圖片與對話會送到你目前選用的服務商處理；免費層的內容可能被用於改進產品，請不要上傳不想外流的資料。資料存在這台裝置的瀏覽器，請開啟雲端同步或定期匯出。
